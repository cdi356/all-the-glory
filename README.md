# ALL THE GLORY

A 3D open-world crime comedy about hacking, rogue AI, stolen cars and taking down the worst bank in the city. Everything (city, desert, forest, characters, cars, guns, sound, music) is generated by code; there are no asset files.

## Play

Download **`ALL THE GLORY.exe`** (in `release/` after building) and double-click it. One file, nothing to install. The first launch takes a few seconds while it unpacks. A dedicated GPU is recommended; the game lowers its internal resolution on its own if the frame rate drops. F11 or Alt+Enter toggles fullscreen.

## LAN co-op (laptop + desktop)

Both computers run `ALL THE GLORY.exe` and must be on the same Wi-Fi or router.

1. **Host:** LAN co-op > **Host a game**. You get a 4-character code like `K7QX`.
2. **Joiner:** LAN co-op > type the code (and a name) > **Join**, then pick a character.
3. **Host:** press **Start: new game** or **Start: continue**. Everyone in the lobby drops in. Anyone can also join later, mid-game, with the same code.

The first time, Windows asks about the firewall on both computers: allow ALL THE GLORY on **private** networks. If the code is not found, the host's screen shows its address under "Code not working?", and the joiner can type that address into the code box instead.

The host runs the world and keeps the save. Up to three players. The joiner's own movement, driving, jumping and gunshots react instantly on their screen, and the connection survives bad Wi-Fi (important messages are never dropped). A friend without the .exe can open the host's address in Chrome or Edge.

## What is in it

- **Saint Vesper**: 13 x 13 blocks, 8 districts, a huge central park with a lake, two enterable skyscrapers with elevators to the roof (Goldman Tower and Halcyon Spire), the Velvet Ledger club, beach, harbor, day/night, rain, traffic
- **Beyond the city**: the **Dry Margin** desert (south-west: mesas, dry lake airstrip, motel, a bunker), **Halfmoon Ridge Reserve** (north-east: forest, a river canyon and the giant **Long Goodbye** suspension bridge), and **Fort Fortis** military base (north; restricted, it fights back)
- **Jeremiah, Jakob, Donald**: switch any time off-mission (Z), each with an ability (T) and a signature weapon
- **30 story missions** in five acts, including Floor 66 (Goldman Tower), the board-key hunt across the desert, the Halcyon Spire roof and the Velvet Ledger, and stealing a VTOL from Fort Fortis
- **Guns in three tiers**: Street (early), Pro (mid, sold after act II), Black-Ops (late, loot only: Fort Fortis, the bunker, bosses, questlines). Enemies drop loot that matches how far you are
- **Workbench**: sight, grip, magazine and stock attachments (plus suppressor, special rounds, finishes and upgrades). The gun lies on the bench and every part snaps on live with its stats. Attachments show on the gun in your hands
- **About 50 cars based on real ones** in five rarities (Common to Legendary); rarer in real life means rarer on the street, and rich districts get the exotics
- **Garage** (Nova's Torque Temple, or the hideout garage): paint, finishes, liveries, wheels, ride height, spoilers, hoods, body kits, exhausts, underglow, plus engine (turbo, supercharger, twin turbo; the hood opens so you can see it), transmission, brakes, suspension, tires, armor and nitrous. All previewed live on a turntable
- **Body armor** in four tiers, visible on your character; **wardrobe** with styles, colours, hair, hats, glasses and beards
- **Wanted stars**: 1 a patrol tails you, 2 they chase but give up quickly, 3 harder to shake, 4 units radio each other and call backup, 5 the whole city hunts you and always knows where you are
- **Questlines**: Ranger Dale (Bigfoot), Roxy at the Velvet Ledger (the colonel's keycard, the armory), Nova's Legends (three legendary cars). **Eight secrets** to find
- Dating, hideout, hacking, races, fixer gigs, golden ducks, casino, perks, cyberware, businesses

## Split-screen co-op

Off by default. Turn it on in **Settings > Split-screen co-op**, then use the title screen button or pause > Co-op. Player 1 uses keyboard and mouse, others use a controller each (press Start to join).

## Develop

```
npm install
npm run dev      # http://localhost:5199, rebuilds on every reload
npm run build    # writes dist/all-the-glory.html
npm run app      # runs the desktop app from source
npm run exe      # builds release/ALL THE GLORY.exe (portable, one file)
```

`src/core` engine, `src/world` city, outer world (`outer.js`), park and skyscrapers (`cityplus.js`), interiors; `src/ent` characters, vehicles, car list and mods (`carmods.js`); `src/sys` gameplay (arsenal/attachments, gear/armor, places, police, net); `src/story` missions and questlines; `src/ui` HUD, menus, garage, workbench; `electron/` the desktop app, LAN server and room-code discovery (UDP port 47788, TCP 5188).

LAN: `src/sys/net.js` (host snapshots with delta compression, a reliable event channel, clock sync, client prediction for walking, jumping, driving and shooting) and `tools/lan-core.js` (WebSocket relay). `tools/lantest.js` runs a host and a joiner in one page on the dev server and can fake bad Wi-Fi (`lag(ms, jitter)`). `ATG_E2E=host|join` runs two copies of the desktop app against each other.

Automated playtests: in the dev console run `await G.test.fresh(0); await G.test.run(0)` for a scripted pass of a mission, or load `tools/bot.js` and run `await botAll(0, 30)`.
