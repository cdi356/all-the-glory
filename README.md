# ALL THE GLORY

A 3D open-world crime comedy about hacking, rogue AI, stolen cars and taking down the worst bank in the city. Everything (city, characters, cars, weapons, sound, music) is generated by code; there are no asset files.

## Play

Double-click `PLAY.bat`, or open `dist/all-the-glory.html` in Chrome or Edge. It is one self-contained file. A dedicated GPU is recommended; the game lowers its internal resolution on its own if the frame rate drops.

Saves live in the browser's local storage for that file, so keep using the same browser.

## What is in it

- **Saint Vesper**: 13 x 13 blocks, 8 districts, elevated expressways, beach, harbor, day/night, rain, traffic with working lights, pedestrians, 29 interiors
- **Jeremiah, Jakob, Donald**: switch any time off-mission (Z), each with an ability (T) and a signature weapon: SUDO, THE MUFFLER, COIN-OP
- **30 story missions** in five acts, checkpointed. Larry Goldman waits at the end. One of the three dies, chosen at random each playthrough
- **Dating**: Nova, Priya, Echo, Tess. Four optional dates each, gifts, choices. Partners give perks, show up in the finale and change the epilogue
- **Hideout**: the Suds of Anarchy laundromat. Sleep/save, workbench, wardrobe, garage, AI operations with Crumb the toaster
- **33 weapons plus fists, 7 throwables**, attachments, upgrades, 17 usable items and gifts
- **Hacking**: scan mode, 24 quickhacks, breach minigames, drone piloting, smart traffic lights, ATMs
- **22 vehicles** including a VTOL, with damage, tuning, theft, chop shop
- **Wanted system** (5 stars), bank and store robberies, 5 races, fixer gigs, 25 golden ducks, random Repo encounters, casino, 35 perks, 14 cyberware implants, 6 businesses

## LAN co-op (laptop + desktop)

1. On the computer that hosts, run `HOST LAN GAME.bat` (needs Node.js there only). Leave the black window open. If Windows asks about the firewall, allow Node.js on **private** networks
2. In the game: **LAN co-op** > **Host**, then Continue or New game. Or host mid-game from pause > **Co-op**
3. On the other computer, open the address shown (like `http://192.168.1.20:5188`) in Chrome or Edge and pick a character. Nothing to install there

Up to three players across computers. The host's computer runs the world and keeps the save; each joiner draws the game itself with its own full screen, HUD, menus, shops and hacking minigames. Pausing does not stop the world, and the host's game window must stay visible (a minimized tab stops the world).

## Split-screen co-op

Two or three players on one screen, through the whole story. Title screen > **Split-screen co-op**, or pause > **Co-op** at any time.

- Player 1: keyboard and mouse. Others: one controller each (press Start during co-op play to join), plus one player on the right side of the keyboard (arrows + number pad)
- Each player is one of the crew with their own camera, HUD, hacking and ability; money, weapons, ammo and RAM are shared
- Two players split top/bottom or side by side; three players get a quarter each and a shared map. Cutscenes go full screen
- Go down and a teammate can help you up; if everyone goes down the mission restarts from its checkpoint
- Anyone can complete objectives, drive, or ride shotgun and shoot. Drop in and out freely

Controls are in the pause menu. Controllers work in solo, menus and minigames too.

## Develop

```
npm install
npm run dev      # http://localhost:5199, rebuilds on every reload
npm run build    # writes dist/all-the-glory.html
```

`src/core` engine, `src/world` city and interiors, `src/ent` characters and vehicles, `src/sys` gameplay systems, `src/story` missions and dates, `src/ui` HUD and menus.

In co-op, code for one player runs inside `G.coop.run(ctx, fn)`, which swaps in that player's `G.player`, `G.cam`, `G.ctl`, `G.hud` and `G.hack` (see `src/sys/coop.js`). Use `G.isH(actor)`, `G.nearH(pos)`, `G.hdist(pos)` and `G.bind(callback)` instead of comparing with `G.player`.

LAN: `src/sys/net.js` (host snapshots, joiner replication and prediction) and `tools/lan-core.js` (WebSocket relay, no dependencies). `tools/lantest.js` runs a host and a joiner in one page on the dev server.

Automated playtests: in the dev console run `await G.test.fresh(0); await G.test.run(0)` for a scripted pass of a mission (add `, 6000, true` to also die once per stage), or load `tools/bot.js` and run `await botAll(0, 30)` for a bot that plays through normal input.
